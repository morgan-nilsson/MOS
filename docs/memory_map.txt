Physical Memory Map:
0x00000000–0x00000FFF   | IVT and BIOS data area | Reserved
0x00500–0x00FFF         │ boot_info: header with version and size, then arrays with counts
0x01000–0x06FFF         │ boot2
0x07000–0x07BFF         │ Real-mode boot stack
0x07C00–0x07DFF         │ boot1
0x10000–0x1FFFF         │ Disk read buffer
0x20000–0x9FBFF         │ Free; reusable after boot
0x9FC00–0xFFFFF         │ Extended BIOS data area, VGA, ROM
0x100000–_kernel_end    │ Kernel image
>                       | Boot time allocs, the free

Virtual: 
Direct map, including the kernel image │ 0xC0000000–0xCFFFFFFF
Kernel heap                            │ 0xD0000000–0xDFFFFFFF
Kernel stacks                          │ 0xE0000000–0xEFFFFFFF
MMIO                                   │ 0xF0000000–0xFFBFFFFF
Recursive page tables                  │ 0xFFC00000–0xFFFFFFFF
